# 清明上河圖・動

會動的清明上河圖（清院本，1736）。用 three.js 製作，不需建置步驟，可直接以靜態網站部署到 Vercel。

- **畫卷模式**：整卷 34,052 × 1,024 px 圖磚。河水會流動，行人、車轎、船隻、飛鳥都會動，可自動展卷。
- **滾輪向下**：先放大畫面，再以水墨暈染的方式轉進 3D 畫中世界，位置對應目前看的那一段。
- **上帝視角**：可拖曳、旋轉、縮放。滾輪拉到最遠會回到平面畫卷。
- **人物視角**：點選畫中任何一人（或按「人」），用他的眼睛逛這座城。
- **自由漫步**：用 WASD 走進街巷、走上虹橋。

## 製作方式

| 部分 | 來源 |
|---|---|
| 畫卷 | 清院本《清明上河圖》，國立故宮博物院藏，公有領域（Wikimedia Commons 56,531 × 1,700 原檔），由 `tools/tile.py` 切成圖磚 |
| 人物、牲口、車轎、樹木、船隻 | Gemini 依原畫局部風格生成精靈圖，再由 `tools/sprites.py` 去背並打包成圖集 |
| 3D 城市 | `src/layout.js` 依原畫逐段手工標註河道、街道、街區、地標；`src/arch.js` 程式化生成屋頂、店鋪、四合院、宮殿、城門、虹橋、船 |
| 畫風 | `src/post.js`：墨線描邊、礦物色調、絹紋與做舊 |

## 本機執行

```
python -m http.server 8000
```

## 檔案

- `src/main.js`：模式切換、2D↔3D 轉場、輸入
- `src/scroll2d.js`：平面動態長卷
- `src/world.js`：3D 世界（地形、河、建築、樹、船）
- `src/crowd.js`：人群模擬（2D 與 3D 共用）
- `src/cameras.js`：上帝視角、人物視角、自由漫步
- `src/layout.js`：畫卷標註資料與畫面↔世界座標對應
